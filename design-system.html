A Simple Design System

One small set of color, type and shape rules.

Most design inconsistency comes from small, unrecorded decisions — a slightly different green here, a new corner radius there. This system records those decisions once, so designers and developers reuse them instead of re-deciding, and every screen looks like it belongs to the same product.
